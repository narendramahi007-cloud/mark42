180+ Real Interview Questions & Explanations

1. What is Azure Key Vault and why do we use it?
To securely store and manage secrets, keys, and certificates.
To store large backup files and images.
To manage Virtual Machine IP addresses.
Answer: It is a centralized cloud service to protect sensitive data. It ensures credentials are not hardcoded in code, providing a secure way to manage secrets.
2. Why should the Terraform State file be stored on a Remote Backend?
To enable team collaboration and prevent state corruption via State Locking.
To save disk space on the local machine.
To hide the design from other team members.
Answer: It maps real resources to code. Remote storage allows team access, encryption at rest, and prevents two people from running 'apply' simultaneously (Locking).
3. What is 'Drift' in Terraform?
The difference between the actual Azure resources and the Terraform code.
A command to move resources between regions.
A way to delete the state file.
Answer: Drift occurs when real infrastructure changes (manually) and doesn't match the code. Terraform detects this during 'plan' and tries to reconcile it.
4. Explain Azure Storage Redundancy (LRS, GRS, ZRS).
Redundancy ensures data durability during hardware or regional failures.
It is used to increase VM RAM speed.
It is a mandatory billing requirement.
Answer: LRS is 3 copies in one DC. ZRS is across 3 zones in one region. GRS is replication to a secondary region for disaster recovery.
5. What is a Network Interface Card (NIC)?
The bridge between an Azure VM and its Virtual Network.
A type of physical hard drive.
A software for writing scripts.
Answer: Every VM needs a NIC to connect to a VNet. It holds the private and public IP configurations and handles all network traffic for that instance.
6. What is the role of an API in Azure?
A bridge that allows different software applications to talk to each other.
A type of firewall.
A billing tool.
Answer: It acts as a messenger that takes your order (request) to the system and brings back the response. It allows tools like Terraform to automate Azure resources.
7. What happens if your State file is deleted?
Terraform loses track of resources; you must 'import' them back.
Azure resources are also deleted.
Nothing happens.
Answer: Deleting state doesn't delete cloud resources, but Terraform won't know they exist. You must enable versioning on your remote backend to recover it.
8. What is State File Locking?
It prevents multiple users from modifying the state at the same time.
It locks the cloud billing.
It encrypts the .tf files.
Answer: When 'apply' is running, Terraform locks the state file. If another person tries to deploy, they will get a 'locked' error to prevent corruption.
9. Difference between VM and Docker?
VM has its own OS; Docker shares the host OS.
Docker is heavier than VM.
VMs run faster.
Answer: Docker containers are lightweight and start in seconds because they don't boot an entire OS. VMs use a hypervisor and are more isolated but heavy.
10. What is a Pod in Kubernetes?
The smallest deployable unit containing one or more containers.
A group of physical servers.
A database table.
Answer: Containers run inside Pods. Kubernetes manages Pods, providing them with IPs and ensuring the desired number of instances are always running.
11. What is Hub and Spoke networking?
A centralized Hub VNet for shared services and Spoke VNets for workloads.
A way to connect VMs via USB.
A star topology in a local office.
Answer: Common in Enterprises. Shared resources (Firewall, VPN) sit in the Hub. Application VNets (Spokes) connect to the Hub via VNet Peering.
12. Explain Blue-Green Deployment.
Using two identical environments to switch traffic between versions.
Testing code in different colors.
A type of security monitoring.
Answer: Blue is current live, Green is new version. Once Green is tested, the Load Balancer switches 100% traffic to Green. This allows zero-downtime releases.
13. What is CI/CD?
Continuous Integration and Continuous Deployment/Delivery.
Cloud Integration and Cloud Design.
Coding and Designing.
Answer: It automates building, testing, and deploying. CI merges code frequently; CD delivers that code to production automatically or with approval.
14. What is the role of an Agent in Azure DevOps?
The machine that runs the tasks/commands in your pipeline.
The person who writes the YAML file.
The cloud provider support.
Answer: Agents download the code, run scripts, and deploy artifacts. You can use Microsoft-hosted or Self-hosted agents on your own VMs.
15. What is RBAC?
Role-Based Access Control to manage permissions.
Remote Backup and Archive Control.
A networking protocol.
Answer: Instead of giving permissions to users individually, you assign roles (Owner, Reader, Contributor) to manage who can do what.
16. What is CIDR?
A method to allocate IP addresses and IP routing.
A cloud storage type.
A coding language.
Answer: Classless Inter-Domain Routing defines network sizes (e.g., /24). It determines how many IPs are available in your VNet or Subnet.
17. Difference between Hot, Cool, and Archive tiers?
Based on access frequency and cost.
Based on storage speed.
Based on data size.
Answer: Hot is for daily data. Cool is for data accessed once a month. Archive is for data stored for 180+ days with lowest cost but highest access time.
18. What is a 'Module' in Terraform?
A container for multiple resources used together (reusable code).
A single .tf file.
A plugin for Azure.
Answer: Modules help in writing DRY (Don't Repeat Yourself) code. You can use one module to create VNets in Dev, QA, and Prod environments.
19. What is 'Managed Identity'?
An identity for Azure resources to authenticate without secrets in code.
A user login for the Portal.
A type of SSH key.
Answer: It eliminates the need for managing credentials. A VM can use its Managed Identity to fetch a secret from Key Vault securely.
20. What is 'Soft Delete' in Storage?
Allows recovery of deleted blobs within a retention period.
Deleting data without confirmation.
Moving data to the bin.
Answer: It's a safety net. If someone accidentally deletes a blob, you can restore it within the set number of days (e.g., 7 days).

21. Difference between count and for_each?
count uses indices (0,1); for_each uses unique keys from a map/set.
count is faster.
for_each is only for Azure.
Answer: for_each avoids index-shifting bugs. If you delete an item in 'count', Terraform might recreate all following resources incorrectly.

To delete resources faster.

Answer: Use it when a resource relies on another without direct attribute reference (e.g., an RBAC role needed before a service).

A storage tier.
Answer: It monitors live web applications, detects performance anomalies, and helps understand what users actually do with your app.
